How it works

Pick the job first. Deckle asks for the file second.

Most PDF sites make you hand over the document before they tell you what happens to it. Deckle works the other way round, and the file never travels.

Choose your tool

Six tabs across the top — Convert, Organise, Edit, Security, Optimise, Advanced. Or search by name.

Add your file

Drop it in or browse. It is read straight from your disk into the tab. Nothing is transmitted.

Save the result

Choose where it lands on your machine. Save as PDF, Word, images, text, Markdown or HTML.

Why redaction is different here

A black box is not redaction.

Most tools draw a rectangle over sensitive text and call it done. The words are still in the file — anyone can select, copy or extract them. This is how documents leak.

When Deckle redacts, it rebuilds the affected pages from pixels at 220 DPI with the marks painted in. The original text stops existing in the file. Pages you did not touch keep their selectable text.

The trade-off is stated plainly in the editor: redacted pages are no longer searchable. That is the cost of the text actually being gone.

Covered with a box elsewhere

$ pdftotext leaked.pdf –
Account 4111 1111 1111 1111

Redacted with Deckle

$ pdftotext redacted.pdf –
(no match — the text is gone)

Questions

Straight answers, including the limits.

Is my file really never uploaded?

Yes, and it is enforced rather than promised. The extension declares no host permissions and no content scripts, and Chrome's extension security policy blocks it from loading remote code. Every library it needs is bundled inside. Turn off your Wi-Fi and every tool still works — that is the simplest way to check for yourself.

What happens to my documents afterwards?

Nothing, because nothing is stored. Files are read into the browser tab, worked on, and saved where you choose. Close the tab and the working copy is gone. There is no server, no history and no log.

Are there size or page limits?

Deckle imposes none. The real ceiling is your browser's memory. Page-by-page work such as exporting images releases each page as it goes, so long documents stay manageable, and saving streams directly to disk where your browser supports it.

Does it handle scanned documents?

Not yet. Text recognition needs a language pack of roughly 15 MB, which would dominate the download, so OCR is not switched on. If your PDF is a scan, the text tools will come back empty. Every other tool works normally.

How accurate is PDF to Word?

Good for text-led documents. Headings, paragraphs and reading order carry across, and wrapped lines are rejoined so the text reflows properly in Word. Complex tables, multi-column layouts and embedded images are not reconstructed.

Can I use it at work with confidential files?

That is what it was built for. Because the document never leaves the machine, using Deckle on a contract or a medical record is the same as opening it in a local application. Check your own IT policy on installing extensions, and note that the permissions list is short enough to hand to a security reviewer.
